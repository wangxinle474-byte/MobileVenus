# IntelligenceCamera — 研究 PRD (Product Requirements Document)

> 版本: v1.1 | 日期: 2026-03-27 | 状态: 研究阶段
> 配套: `docs/product_prd.md` (面向 C 端 App 产品的 PRD)

## 1. 产品定位

### 1.1 一句话描述

> 将 Venus 7B 大模型的摄影美学理解能力压缩 1000 倍，部署到手机上，实时输出 8 个可解释的 Lightroom 调参建议。

### 1.2 背景与动机

| 现有方案 | 问题 |
|---------|------|
| 手动调参 (Lightroom) | 学习成本高，普通用户无法使用 |
| 滤镜/预设 | 一刀切，不考虑图片内容 |
| HDRNet / 3D LUT / CSRNet | 像素级黑盒，不可解释，不可手动微调 |
| Venus 7B 大模型 | 效果好但 14GB，无法端侧部署 |

**核心问题**: 如何在手机端实现既智能（理解图片内容）又可解释（用户可微调）的图像增强？

### 1.3 核心创新

**语义蒸馏 (Semantic Distillation)**：不是把 Venus 的"回答"压缩，而是把它的"思考过程"压缩。

```
Venus 推理链:   图片 → 自然语言理解 → 参数建议
IntelligenceCamera:   图片 → 语义空间(学到的) → 参数预测
```

首次将 VLM (Vision-Language Model) 的自然语言美学理解能力蒸馏为可解释相机参数预测。

## 2. 目标用户

### 2.1 主要用户

**摄影爱好者 / 手机摄影用户**
- 不熟悉 Lightroom 参数含义
- 希望照片更好看但不知道从哪里调起
- 有时候想微调单个参数（比如只调色温）

### 2.2 次要用户

**专业摄影师（辅助工作流）**
- 用于快速生成参数建议，再手动精调
- 输出参数可直接导入 Lightroom / Camera Raw

### 2.3 研究用户

**CVPR 评审 / 同行研究者**
- 关注语义蒸馏方法的有效性
- 需要与 SOTA 方法的定量对比

## 3. 功能需求

### 3.1 核心功能

#### F1: 图像参数预测
- **输入**: 一张 RGB 图片（任意分辨率）
- **输出**: 8 个 Lightroom 参数

| 参数 | 物理范围 | 说明 |
|------|---------|------|
| EV Compensation | [-3, 3] EV | 曝光补偿 |
| White Balance | [2000, 10000] K | 色温 |
| Contrast | [-100, 100] | 对比度 |
| Brightness | [-100, 100] | 亮度 |
| Shadows | [-100, 100] | 阴影 |
| Highlights | [-100, 100] | 高光 |
| Saturation | [-100, 100] | 饱和度 |
| Vibrance | [-100, 100] | 自然饱和度 |

- **延迟要求**: 端侧推理 < 80ms（移动设备）
- **模型大小**: < 30MB（可 OTA 更新）

#### F2: 图像渲染
- 使用 Gamma-aware ISP Pipeline 将预测参数应用到原图
- 支持实时预览
- 处理顺序: EV → White Balance → Contrast → Brightness → Shadows → Highlights → Saturation → Vibrance

#### F3: 参数可解释输出
- 输出参数需可读（非归一化值，直接对应 Lightroom 刻度）
- 支持用户手动覆盖任意单个参数后重渲染

### 3.2 非功能需求

#### F4: 跨设备兼容
- 支持 iOS / Android 端侧推理（PyTorch Mobile / CoreML）
- 最低目标设备: 中端 Android（骁龙 7 系）

#### F5: 可解释性接口（研究用）
- 可视化语义向量（Stage A 输出）的 t-SNE 分布
- 提供按参数分解的置信度

## 4. 系统架构

### 4.1 整体流程

```
训练阶段:
  Venus 7B → 自然语言分析 → 文本嵌入 (MiniLM)
                                ↑ 对齐
  图片 → MobileViT → SemanticProjector → 语义向量
                                ↓
                      ParameterDecoder → 8 参数

推理阶段 (无需 Venus):
  图片 → MobileViT → SemanticProjector → ParameterDecoder → 8 参数
```

### 4.2 模型组件

| 组件 | 实现 | 参数量 | 作用 |
|------|------|--------|------|
| Backbone | MobileViT-S | ~5.6M | 图像特征提取 |
| SemanticProjector | 3层 MLP | ~0.3M | 对齐语义空间 |
| ParameterDecoder | 2层 MLP | ~0.1M | 参数回归 |
| **总计** | | **~6M (24MB)** | |

**教师模型** (训练时使用，推理不需要):
- Venus-Q-Stage1: 7B 参数，14GB
- 文本编码器: sentence-transformers/all-MiniLM-L6-v2

### 4.3 训练两阶段

**Stage A: 语义对齐**
- 目标: 让 MobileViT+SemanticProjector 的输出对齐 Venus 文本嵌入
- 损失函数: Alignment Loss + Uniformity Loss
- 数据: 5,377 张 Venus 分析图片 + 文本嵌入

**Stage B: 参数微调**
- 目标: 在 Stage A 的语义空间基础上学习参数预测
- 损失函数: MSE（8 参数加权）
- 数据: MIT-Adobe FiveK 46,167 条专家调参记录

## 6. 评估指标

### 6.1 图像质量 (主要指标)

| 指标 | 含义 | 目标值 | 当前最优 |
|------|------|--------|---------|
| PSNR ↑ | 像素级失真 | > 33 dB | **33.15 dB** (Distill v2) |
| SSIM ↑ | 结构相似度 | > 0.93 | **0.9311** (Distill v2) |
| Δ PSNR vs Baseline | 蒸馏增益 | > +1.0 dB | **+1.10 dB** |

### 6.2 参数精度 (辅助指标)

各参数 MAE（物理单位）:

| 参数 | Baseline | Distill v2 | 改进 |
|------|---------|------------|------|
| EV | 0.09 EV | **0.06 EV** | ↓33% |
| White Balance | 502 K | 620 K | ↑ (协调提升整体) |
| Contrast | 7.47 | 7.44 | ≈ |
| Brightness | 3.77 | 3.81 | ≈ |
| Shadows | 6.38 | **5.83** | ↓9% |
| Highlights | 7.53 | 6.99 | ↓7% |
| Saturation | 1.35 | 1.46 | ↑ |
| Vibrance | 6.06 | 6.50 | ↑ |

> 注: 部分参数 MAE 升高但整体 PSNR 更优，说明蒸馏学会了参数协调而非逐参数优化。

### 6.3 美学评估 (教师验证) ✅ 已完成

使用 Venus 对三组图片评分（50张，1-10 分）:

| 维度 | Original | Baseline | Distill v2 | Delta |
|------|---------|---------|-----------|-------|
| Lighting | 5.32 | 5.14 | **5.51** | +0.19 |
| Color | 5.20 | 5.16 | **5.36** | +0.16 |
| Clarity | 5.20 | 5.14 | **5.36** | +0.16 |
| Subject | 5.18 | 5.14 | **5.38** | +0.20 |
| **Overall** | 5.22 | 5.06 | **5.36** | **+0.14** |

**结论**: Distill v2 > Original (+0.14)，Baseline < Original (-0.16)。**语义蒸馏是决定性因素**，使 Venus 评分提升 +0.30（vs baseline）。

### 6.4 NIMA-Aesthetic 评估 ✅ 已完成

使用 pyiqa (NIMA InceptionV2, AVA 权重) 对同组 50 张图片独立打分:

| 组别 | NIMA 均值 | Delta vs orig |
|------|---------|--------------|
| Original | 4.5265 | — |
| Baseline | 4.4289 | -0.0976 |
| **Distill v2** | **4.4360** | **-0.0905** |

**结论**: Distill v2 > Baseline，与 Venus 排名一致。两模型均略低于原图（FiveK 原图为专业 RAW，NIMA/AVA 偏好竞赛风格，属已知局限）。

**三指标综合结论**:

| 指标 | Distill v2 vs Baseline | 方向 |
|------|----------------------|------|
| PSNR | +1.10 dB | v2 胜 |
| Venus Overall | +0.30 | v2 胜 |
| NIMA | +0.0071 | v2 胜 |

> **语义蒸馏有效性获 PSNR + Venus + NIMA 三维度独立验证**

### 6.5 效率指标

| 指标 | 目标 | 备注 |
|------|------|------|
| 推理延迟 | < 80ms | 移动设备 |
| 模型大小 | < 30MB | 端侧部署 |
| 压缩比 | ≥ 1000x | vs Venus 7B |

## 7. 当前实验结果

### 7.1 PSNR/SSIM/MS-SSIM 汇总

| 模型 | Stage A 数据 | PSNR ↑ | SSIM ↑ | MS-SSIM ↑ | Δ PSNR |
|------|------------|--------|--------|-----------|--------|
| Baseline | N/A | 32.05 | 0.9269 | 0.9805 | — |
| Distill v1 | 3K COCO | 33.09 | 0.9257 | 0.9802 | +1.04 |
| **Distill v2** | **3K COCO** | **33.15** | 0.9311 | **0.9813** | **+1.10** |
| Distill v3 | 5.3K COCO | 32.85 | 0.9278 | 0.9811 | +0.80 |
| **Distill v4** | **2K FiveK域** | 33.11 | **0.9326** | **0.9813** | +1.06 |

### 7.2 关键发现

1. **语义蒸馏有效**: +1.10 dB PSNR，验证了核心假设
2. **域偏移警示**: 更多 Stage A 数据 (v3, 5.3K COCO) 反而退步——数据质量/域匹配比数量更重要
3. **v4 验证域对齐假设**: FiveK 域 Stage A 数据 → SSIM=0.9326（全局最优），比 v2 高 +0.0015
4. **PSNR vs SSIM 权衡**: v4 PSNR 略低于 v2 (33.11 vs 33.15)，但 SSIM 更高，感知质量更好
5. **参数协调**: 蒸馏模型不是在逐参数上更准，而是学会了参数之间的协调（整体质量优于部分参数 MAE 更高）

### 7.3 多专家一致性验证

| 模型 | Expert-Default | Expert-A (168张) | Expert-B (19张) |
|------|---------------|-----------------|----------------|
| Baseline | 32.17 / 0.9348 | 32.47 / 0.9324 | 17.43 / 0.8088 |
| **Distill v2** | **33.10** / **0.9393** | **33.82** / **0.9391** | 17.54 / 0.8019 |
| **Distill v4** | 33.11 / 0.9378 | 33.73 / 0.9383 | 17.49 / 0.7974 |

> **结论**: Distill 模型在 **独立测试专家 Expert-A** 上同样超越 Baseline (+1.35 dB PSNR)，验证了跨标注者的泛化性。Expert-B 风格过于独特，所有模型均无法适应，这是已知的有限性。

## 8. 已知风险与限制

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| Stage A 数据域偏移 | v3 退步 0.30 dB | 筛选与 FiveK 同域的图片做 Stage A |
| 白平衡 MAE 偏大 | 色温预测不稳 | 增加白平衡专项数据增强 |

| PSNR 作为主指标的局限 | 不直接反映美学 | Venus ✅ + NIMA ✅ + MS-SSIM ✅ 多维度验证 |

# Part 2: App PRD — LightAI

> 版本: v1.0 | 日期: 2026-03-27 | 产品阶段: MVP 规划

## 1. 产品概述

### 1.1 产品名称

**LightAI** (暂定) — AI 驱动的智能调参摄影助手

### 1.2 产品愿景

> 让每个人都能拥有一位随身的专业摄影师——拍完照片，AI 立即理解画面内容，给出专业级的调参建议，用户可以一键应用或手动微调。

### 1.3 核心价值主张

| 维度 | 竞品（滤镜类 App） | LightAI |
|------|--------------|---------|
| 智能程度 | 固定滤镜，不看内容 | 理解每张照片的光线/色彩/主体 |
| 可解释性 | 黑盒，不知道做了什么 | 显示每个参数的调整值和原因 |
| 可编辑性 | 无法微调单项 | 可手动调整任意单个参数 |
| 兼容性 | 封闭生态 | 参数可导出到 Lightroom / Snapseed |
| 速度 | 快 | < 100ms 端侧推理，实时预览 |

## 2. 目标用户

### 2.1 主要用户 — 摄影爱好者

**人物画像**: 25-40 岁，日常用手机拍照，有审美追求但不懂专业后期

**痛点**:
- 知道照片"看起来不够好"，但不知道从哪里调
- 试过滤镜，但感觉不自然或不适合当前照片
- 想学 Lightroom 但学习成本太高

### 2.2 次要用户 — 轻度专业用户

**人物画像**: 摄影发烧友、自媒体创作者，会使用 Lightroom 但希望加速工作流

### 2.3 非目标用户

- 专业商业摄影师（需要极精细的手动控制）
- 视频创作者（本期不涉及视频）

## 3. 核心功能需求

### F1: 智能参数预测 [P0]

用户选择一张照片，App 在 < 100ms 内输出 8 个 Lightroom 参数。

**验收标准**:
- 推理延迟 < 100ms（中端 Android，骁龙 7 系）
- 模型大小 < 30MB（支持 OTA 更新）
- 离线可用（不依赖网络）

### F2: 实时预览与对比 [P0]

- **滑动对比** (Split-view)：左原图/右增强，滑动分隔线
- **双击切换**：快速原图 <-> 增强图
- **参数微调实时刷新**：滑块拖动时图像实时更新（60fps）

### F3: 参数可视化与解释 [P0]

参数列表卡片，每项显示滑块 + 数值 + 简短说明：
```
曝光 +0.8  ▬▬▬▬▬▌░░░░
"画面偏暗，提亮整体曝光"

色温 5800K  ▬▬▬▌░░░░░░
"白平衡偏冷，调整为中性日光"
```

### F4: 手动微调 [P1]

点击参数卡片展开详细滑块，支持精确数字输入和重置。

### F5: 保存与导出 [P1]

| 格式 | 说明 | 优先级 |
|------|------|--------|
| JPEG 全分辨率 | 保存增强图到相册 | P0 |
| Lightroom XMP 预设 | 在桌面端继续精调 | P1 |
| JSON 参数文件 | 开发者/高级用户使用 | P2 |

### F6: 批量处理 [P2]

选择多张照片，批量应用 AI 调参（每张独立推理），初版限制最多 20 张/批次。
