## 1. 产品概述

### 1.1 产品名称

**LightAI** (暂定) — AI 驱动的智能调参摄影助手

### 1.2 产品愿景

> 让每个人都能拥有一位随身的专业摄影师——拍完照片，AI 立即理解画面内容，给出专业级的调参建议，用户可以一键应用或手动微调。

### 1.3 核心价值主张

| 维度 | 竞品（滤镜类 App） | LightAI |
|------|--------------|---------|
| 智能程度 | 固定滤镜，不看内容 | 理解每张照片的光线/色彩/主体 |
| 可解释性 | 黑盒，不知道做了什么 | 显示每个参数的调整值和原因 |
| 可编辑性 | 无法微调单项 | 可手动调整任意单个参数 |
| 兼容性 | 封闭生态 | 参数可导出到 Lightroom / Snapseed |
| 速度 | 快 | < 100ms 端侧推理，实时预览 |

## 2. 目标用户

### 2.1 主要用户 — 摄影爱好者

**人物画像**: 25-40 岁，日常用手机拍照，有审美追求但不懂专业后期

**痛点**:
- 知道照片"看起来不够好"，但不知道从哪里调
- 试过滤镜，但感觉不自然或不适合当前照片
- 想学 Lightroom 但学习成本太高

**期望**:
- 一键让照片变好看
- 了解"哪里不好、为什么这样调"
- 结果可以进一步微调

### 2.2 次要用户 — 轻度专业用户

**人物画像**: 摄影发烧友、自媒体创作者，会使用 Lightroom 但希望加速工作流

**期望**:
- 快速获得参数建议作为起点
- 批量处理多张图片
- 一键导出 Lightroom 预设文件 (.xmp)

### 2.3 非目标用户

- 专业商业摄影师（需要极精细的手动控制）
- 视频创作者（本期不涉及视频）

## 3. 核心功能需求

### F1: 智能参数预测 [P0]

**描述**: 用户选择一张照片，App 在 < 100ms 内输出 8 个 Lightroom 参数。

**输出参数**:

| 参数 | 显示名 | 范围 | 单位 |
|------|--------|------|------|
| EV Compensation | 曝光 | -3 ~ +3 | EV |
| White Balance | 色温 | 2000 ~ 10000 | K |
| Contrast | 对比度 | -100 ~ +100 | — |
| Brightness | 亮度 | -100 ~ +100 | — |
| Shadows | 阴影 | -100 ~ +100 | — |
| Highlights | 高光 | -100 ~ +100 | — |
| Saturation | 饱和度 | -100 ~ +100 | — |
| Vibrance | 自然饱和度 | -100 ~ +100 | — |

**验收标准**:
- 推理延迟 < 100ms（中端 Android，骁龙 7 系）
- 模型大小 < 30MB（支持 OTA 更新）
- 离线可用（不依赖网络）

---

### F2: 实时预览与对比 [P0]

**描述**: 用户可实时看到参数应用后的效果，支持原图/增强图滑动对比。

**交互形式**:
- **滑动对比** (Split-view)：左原图/右增强，滑动分隔线
- **双击切换**：快速原图 <-> 增强图
- **参数微调实时刷新**：滑块拖动时图像实时更新（< 16ms/帧，60fps）

**验收标准**:
- 滑块响应延迟 < 16ms
- 支持 4K 分辨率图片（降分辨率渲染预览，保存时全分辨率）

---

### F3: 参数可视化与解释 [P0]

**描述**: 展示 8 个参数的调整幅度，并提供简单的中文说明。

**UI 形式**:
- 参数列表卡片，每项显示滑块 + 数值 + 简短说明
- 颜色编码：红色 = 大幅调整，绿色 = 小幅微调，灰色 = 未调整

**说明示例**:
```
曝光 +0.8  ▬▬▬▬▬▌░░░░
"画面偏暗，提亮整体曝光"

色温 5800K  ▬▬▬▌░░░░░░
"白平衡偏冷，调整为中性日光"
```

---

### F4: 手动微调 [P1]

**描述**: 用户可手动调整任意单个参数，其他参数不受影响。

**交互**:
- 点击参数卡片展开详细滑块
- 长按参数值可输入精确数字
- "重置此参数"按钮恢复 AI 建议值
- "重置全部"按钮恢复 AI 初始建议

---

### F5: 保存与导出 [P1]

**描述**: 用户可保存增强后的图片，或导出参数供第三方工具使用。

**导出选项**:

| 格式 | 说明 | 优先级 |
|------|------|--------|
| JPEG 全分辨率 | 保存增强图到相册 | P0 |
| Lightroom XMP 预设 | 在桌面端继续精调 | P1 |
| Snapseed 参数 | 分享给 Snapseed 用户 | P2 |
| JSON 参数文件 | 开发者/高级用户使用 | P2 |

---

### F6: 批量处理 [P2]

**描述**: 选择多张照片，批量应用 AI 调参（每张独立推理）。

**限制**:
- 初版限制最多 20 张/批次
- 后台处理，处理完毕推送通知

---

### F7: 历史记录 [P2]

**描述**: 查看历史调参记录，支持重新编辑或重新应用到其他图片。

## 4. 非功能需求

### 4.1 性能要求

| 指标 | 目标 | 说明 |
|------|------|------|
| 模型推理延迟 | < 100ms | 中端 Android |
| 模型推理延迟 | < 50ms | iPhone 14 以上 |
| 图片渲染帧率 | 60fps | 参数调整实时预览 |
| App 启动时间 | < 2s | 冷启动 |
| 模型大小 | < 30MB | 含模型权重 |
| 安装包大小 | < 80MB | 总安装包 |
| 内存占用 | < 300MB | 运行时峰值 |

### 4.2 兼容性

| 平台 | 最低版本 | 推理框架 |
|------|---------|---------|
| Android | Android 8.0 (API 26) | PyTorch Mobile / NNAPI |
| iOS | iOS 14 | Core ML |

### 4.3 隐私与数据

- **本地推理**：所有 AI 计算在设备端完成，图片不上传服务器
- **无账号要求**：基础功能完全离线可用
- **图片权限**：仅在用户主动选择图片时访问相册，不后台扫描

## 5. 用户旅程

### 主流程（首次使用）

```
1. 下载安装 App
2. 引导页：3 张对比图展示效果（跳过按钮）
3. 首页：大按钮"选择照片"
4. 系统相册选择图片
5. [AI 推理 <100ms] → 推理动画
6. 结果页：
   ├─ 上方: 滑动对比图（原图/增强图）
   ├─ 中间: 8个参数卡片
   └─ 下方: "保存" + "微调" + "导出"
7. 保存到相册
```

### 微调流程

```
结果页 → 点击参数卡片
→ 展开详细滑块
→ 拖动滑块，图片实时更新
→ 满意后点击"保存"
```

## 7. 技术架构

### 7.1 移动端

```
UI Layer (React Native / Flutter)
    ↓
Bridge Layer (Native Module)
    ↓
Inference Engine
├─ Android: PyTorch Mobile (LibTorch) / NNAPI 加速
└─ iOS: Core ML (.mlmodel 格式)
    ↓
MobileVenus 模型 (6M 参数, ~24MB)
├─ MobileViT-S Backbone
├─ SemanticProjector
└─ ParameterDecoder
    ↓
ISP Pipeline (C++ / Swift / Kotlin)
└─ Gamma-aware Lightroom 参数渲染
```

### 7.2 模型格式

| 平台 | 格式 | 工具链 |
|------|------|--------|
| Android | `.ptl` (TorchScript) | `torch.jit.trace` |
| iOS | `.mlpackage` (Core ML) | `coremltools` |
| 通用备用 | `.onnx` | ONNX Runtime Mobile |

### 7.3 模型更新

- 首次安装内嵌基础模型
- 后续模型更新通过 OTA 静默下载（< 30MB 增量更新）
- 支持模型版本回退
